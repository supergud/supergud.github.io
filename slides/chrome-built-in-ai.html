02 · Trade-offs

優勢與代價，兩邊都要講

✓ 優勢

  • 本機處理：資料不必送去雲端推論
  • 沒有逐次雲端 Token 費
  • 模型下載後可離線使用
  • 不用自己部署、維運模型：Chrome 負責管理

✕ 代價

  • 首次下載：模型體積大，需要等待
  • 裝置相容性：不是每台電腦、手機都能用
  • 語言限制：基礎模型支援語言有限
  • 模型能力：小模型，不等於雲端大模型
  • 記憶體與資源消耗：和使用者的其他工作搶資源
⚠ 不要說「所有裝置都能用」，也不要說「本機一定比雲端快」。兩個說法都不成立。
Chrome Built-in AI05 / 22

目的：建立期待管理，避免過度行銷。

講稿：優勢很直白：本機、省 Token 費、可離線、不用顧模型部署。但代價也很實際：第一次要下載，不是每台機器都行，語言支援有限，小模型也比不上大模型，而且吃使用者的記憶體。我特別要強調：沒有人保證本機比雲端快。這是設計取捨，不是魔法。

04 · Getting Started

如何開始使用？

Gemini Nano 系（Prompt、Summarizer）

  • Chrome 桌面版（Prompt 網頁 148、擴充 138）
  • Windows 10/11 · macOS 13+ · Linux · Chromebook Plus
  • 可用空間 ≥ 22 GB（Chrome 設定檔所在磁碟）
  • GPU VRAM > 4GB，或 16GB RAM + 4 核心 CPU
  • 首次下載需不計量網路

Translator · Language Detector

  • Chrome 桌面版 138（穩定版）
  • 使用專用模型，不套用上面的 Gemini Nano 硬體門檻
  • 依語言對下載語言套件
  • 不支援行動裝置、不可用於 Web Worker
  • Translator.create() 需要使用者操作（user activation）

🔒 安全環境：HTTPS 或 localhost

🔧 chrome://on-device-internals 查看模型狀態

🧪 Web AI Studio 與官方 Demo 線上試玩

async function translateToZhHant(text, onStatus) {
  if (!('LanguageDetector' in self) || !('Translator' in self)) {
    return { ok: false, reason: 'unsupported' };
  }
  try {
    const detector = await LanguageDetector.create();
    const [top] = await detector.detect(text);
    const src = top.detectedLanguage;
    if (src.startsWith('zh')) return { ok: true, text, skipped: true };

    const pair = { sourceLanguage: src, targetLanguage: 'zh-Hant' };
    const availability = await Translator.availability(pair);
    if (availability === 'unavailable') {
      return { ok: false, reason: 'unavailable', src };
    }
    const translator = await Translator.create({
      ...pair,
      monitor(m) {
        m.addEventListener('downloadprogress', (e) =>
          onStatus(`下載 ${Math.round(e.loaded * 100)}%`));
      },
    });
    const out = await translator.translate(text);
    translator.destroy();
    return { ok: true, text: out, src, confidence: top.confidence };
  } catch (err) {
    return { ok: false, reason: 'error', message: String(err) };
  }
}

async function askLocal(input) {
  if (!('LanguageModel' in self)) throw new Error('unsupported');
  const options = {
    expectedInputs:  [{ type: 'text', languages: ['en'] }],
    expectedOutputs: [{ type: 'text', languages: ['en'] }],
  };
  const availability = await LanguageModel.availability(options);
  if (availability === 'unavailable') throw new Error('unavailable');
  const session = await LanguageModel.create(options);
  try { return await session.prompt(input); }
  finally { session.destroy(); }
}
