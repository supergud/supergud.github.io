一句話分辨

THE SHORT VERSION
WORDPRESS.COM

租用一間已經準備好的店面

平台提供主機、管理介面與維護服務；你用帳號登入即可開始。

WORDPRESS.ORG

下載軟體，自己擁有整棟房子

WordPress 軟體免費開源；你自行選主機、網域與所有客製化方式。

CSS：用規則描述外觀

READ THIS

CSS 的基本句型：

選取器 {
  屬性: 值;
}

讀法：找到誰，改哪一個外觀，改成什麼。

.hero-title {
  color: #c53b2c;
  font-size: 56px;
  margin-bottom: 24px;
}
CSS 不會改變內容，只改變呈現19 / 28

先認得這 6 個屬性

CSS STARTER KIT

color

文字顏色

background

背景顏色或圖片

background: #f2eee6;

font-size

文字大小

font-size: 32px;

margin

元素外部距離

margin: 24px;

padding

元素內部距離

padding: 16px;

border

邊框

border: 2px solid;

DevTools 的修改只在你的瀏覽器暫時生效21 / 28

把修改貼回 WordPress

MAKE IT STICK
APPEARANCE → CUSTOMIZE

額外 CSS

把確認過的規則貼到「額外 CSS」，預覽、儲存、重新整理前台。

注意 3 件事

  • 選取器要夠精準，避免誤傷其他區塊。
  • 必要時用 !important，但不要濫用。
  • 佈景主題更新後，重新檢查自訂樣式。
/* 你的品牌按鈕 */
