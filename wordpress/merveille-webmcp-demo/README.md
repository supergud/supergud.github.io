# Merveille WebMCP Demo

安裝並啟用後，以管理員登入網站，點選上方工具列的 **WebMCP Demo**，或開啟 `/?merveille_demo=1`。

需 WooCommerce。僅管理員可看見面板與呼叫 REST 工具。沒有 API key、外部 AI 服務、訂單建立或付款功能。

原生 WebMCP 可用時註冊 5 個工具。否則明確顯示尚未可用；手動按鈕仍會呼叫真實 WooCommerce 功能，紀錄標示「手動測試」。AI 呼叫標示「WebMCP」。

範例指令：搜尋 500 元以下的耳環，查看一件有庫存且可直接購買的商品，加入購物車 1 件，再列出購物車。不結帳。

清理按鈕只移除本外掛標記的目前管理員 Demo 購物車項目，保留其他項目。商品規格選擇不在此版本範圍內，變化商品需至商品頁處理。

停用外掛即可移除面板與 REST 工具；停用前可用清理按鈕移除 Demo 商品。
